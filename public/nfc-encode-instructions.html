How to Encode NFC Wristbands for OnePass

Follow these steps to properly encode NFC wristbands that work with OnePass verification system.

1

Get Guest NFC ID

Guest NFC ID:

Guest:

2

Install NFC Tools App

Download and install the NFC Tools app by wakdev from Google Play Store.

Download from Play Store
3

Write to NFC Wristband

3.1 Open NFC Tools app

Tap the WRITE tab at the top

3.2 Add a Text Record

Tap "Add a record" → Select "Text"

3.3 Paste NFC ID

Paste the NFC ID you copied in Step 1

Example: NFCMJDE5MY09GTWUVUL

3.4 Write to Wristband

Tap "Write" button, then hold wristband to phone

Keep wristband steady for 2-3 seconds

Success!

You should see "Write successful" message

4

Test the Wristband

Open the scanner page and tap the wristband to verify it works:
