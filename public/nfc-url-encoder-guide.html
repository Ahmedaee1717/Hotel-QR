If you use "Text" record, the phone will just show text. Use "URL" record so it opens the scanner automatically!

3.1 Open NFC Tools

Tap the WRITE tab

3.2 Add a URL Record

Tap "Add a record" → Select "URL / URI"

NOT "Text"! Use "URL / URI"!

3.3 Paste the URL

Paste the URL you copied from Step 1

Example: https://...pages.dev/staff-nfc-scanner.html?nfc=NFCMJDE...

3.4 Write to Wristband

Tap "Write", then hold wristband to phone for 2-3 seconds

Done!
