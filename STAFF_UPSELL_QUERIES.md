# Staff Upsell Performance Tracking

## Overview
The front-desk booking system now tracks which staff member creates each booking via the `created_by_staff_id` field in the `alacarte_vouchers` table.

This enables:
- **Performance tracking** - See which staff members are creating the most bookings
- **Upsell incentives** - Track extra-charge item sales per staff member
- **Revenue attribution** - Calculate revenue generated by each staff member
- **Commission calculations** - Award bonuses based on upsell performance

## Database Schema

### New Column
```sql
ALTER TABLE alacarte_vouchers 
ADD COLUMN created_by_staff_id INTEGER REFERENCES users(user_id);
```

### Indexes
```sql
CREATE INDEX idx_alacarte_vouchers_staff 
ON alacarte_vouchers(created_by_staff_id);

CREATE INDEX idx_alacarte_vouchers_staff_date 
ON alacarte_vouchers(created_by_staff_id, reservation_date);
```

## Useful Queries

### 1. Staff Performance Overview
Get total bookings per staff member:
```sql
SELECT 
  u.user_id,
  u.first_name || ' ' || u.last_name AS staff_name,
  u.role,
  COUNT(v.voucher_id) AS total_bookings,
  SUM(v.party_size) AS total_guests,
  COUNT(CASE WHEN v.status = 'confirmed' THEN 1 END) AS active_bookings,
  COUNT(CASE WHEN v.status = 'used' THEN 1 END) AS completed_bookings
FROM users u
LEFT JOIN alacarte_vouchers v ON u.user_id = v.created_by_staff_id
WHERE u.property_id = ? AND u.status = 'active'
GROUP BY u.user_id, u.first_name, u.last_name, u.role
ORDER BY total_bookings DESC;
```

### 2. Extra Charge Item Sales by Staff
Track upsell performance (extra charge items):
```sql
SELECT 
  u.user_id,
  u.first_name || ' ' || u.last_name AS staff_name,
  COUNT(DISTINCT v.voucher_id) AS bookings_with_extras,
  SUM(v.total_cost) AS total_extra_charge_revenue,
  AVG(v.total_cost) AS avg_extra_charge_per_booking,
  COUNT(*) AS total_extra_items
FROM users u
INNER JOIN alacarte_vouchers v ON u.user_id = v.created_by_staff_id
INNER JOIN json_each(v.preorder_item_ids) AS items
INNER JOIN alacarte_menu_items ami ON ami.item_id = CAST(json_extract(items.value, '$.item_id') AS TEXT)
WHERE ami.cost_to_hotel > 0  -- Only extra charge items
  AND v.property_id = ?
  AND v.reservation_date >= ?  -- Date range filter
  AND v.reservation_date <= ?
GROUP BY u.user_id, u.first_name, u.last_name
ORDER BY total_extra_charge_revenue DESC;
```

### 3. Daily Staff Performance
Track bookings by staff member per day:
```sql
SELECT 
  v.reservation_date,
  u.first_name || ' ' || u.last_name AS staff_name,
  COUNT(v.voucher_id) AS bookings_today,
  SUM(v.party_size) AS guests_today,
  SUM(v.total_cost) AS revenue_today
FROM alacarte_vouchers v
INNER JOIN users u ON v.created_by_staff_id = u.user_id
WHERE v.property_id = ?
  AND v.reservation_date = CURRENT_DATE
GROUP BY v.reservation_date, u.user_id, u.first_name, u.last_name
ORDER BY revenue_today DESC;
```

### 4. Top Upsellers (Last 30 Days)
Find staff members with highest extra-charge revenue:
```sql
SELECT 
  u.user_id,
  u.first_name || ' ' || u.last_name AS staff_name,
  COUNT(DISTINCT v.voucher_id) AS total_bookings,
  SUM(CASE WHEN v.total_cost > 0 THEN 1 ELSE 0 END) AS bookings_with_upsell,
  ROUND(SUM(CASE WHEN v.total_cost > 0 THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) AS upsell_rate_percent,
  SUM(v.total_cost) AS total_upsell_revenue,
  ROUND(AVG(v.total_cost), 2) AS avg_upsell_per_booking
FROM users u
INNER JOIN alacarte_vouchers v ON u.user_id = v.created_by_staff_id
WHERE v.property_id = ?
  AND v.reservation_date >= DATE('now', '-30 days')
  AND v.status IN ('confirmed', 'used')
GROUP BY u.user_id, u.first_name, u.last_name
HAVING total_bookings > 0
ORDER BY upsell_rate_percent DESC, total_upsell_revenue DESC
LIMIT 10;
```

### 5. Commission Calculation Example
Calculate commission for staff based on upsell revenue:
```sql
-- Example: 10% commission on extra charge items
SELECT 
  u.user_id,
  u.first_name || ' ' || u.last_name AS staff_name,
  SUM(v.total_cost) AS total_upsell_revenue,
  ROUND(SUM(v.total_cost) * 0.10, 2) AS commission_earned
FROM users u
INNER JOIN alacarte_vouchers v ON u.user_id = v.created_by_staff_id
WHERE v.property_id = ?
  AND v.reservation_date >= ?  -- Start of month
  AND v.reservation_date <= ?  -- End of month
  AND v.status IN ('confirmed', 'used')
  AND v.total_cost > 0
GROUP BY u.user_id, u.first_name, u.last_name
ORDER BY commission_earned DESC;
```

### 6. Staff Performance Leaderboard
Monthly leaderboard with multiple metrics:
```sql
SELECT 
  u.user_id,
  u.first_name || ' ' || u.last_name AS staff_name,
  COUNT(DISTINCT v.voucher_id) AS total_bookings,
  SUM(v.party_size) AS total_guests,
  SUM(v.total_cost) AS total_revenue,
  COUNT(CASE WHEN v.total_cost > 0 THEN 1 END) AS upsell_count,
  ROUND(COUNT(CASE WHEN v.total_cost > 0 THEN 1 END) * 100.0 / COUNT(*), 1) AS upsell_percentage,
  ROUND(AVG(v.total_cost), 2) AS avg_revenue_per_booking,
  -- Calculate points: 1 point per booking, 5 bonus points per upsell
  COUNT(*) + (COUNT(CASE WHEN v.total_cost > 0 THEN 1 END) * 5) AS leaderboard_points
FROM users u
INNER JOIN alacarte_vouchers v ON u.user_id = v.created_by_staff_id
WHERE v.property_id = ?
  AND v.reservation_date >= DATE('now', 'start of month')
  AND v.status IN ('confirmed', 'used')
GROUP BY u.user_id, u.first_name, u.last_name
ORDER BY leaderboard_points DESC, total_revenue DESC
LIMIT 10;
```

## Implementation Notes

### Frontend Flow
1. **Step 1**: Staff member selects themselves from dropdown
2. System validates staff selection before proceeding
3. Staff ID is included in booking payload
4. Backend stores staff ID in `alacarte_vouchers.created_by_staff_id`

### Validation
- Staff selection is **required** at the front desk
- Only active staff members appear in dropdown
- Staff ID is stored but can be NULL for legacy bookings

### Future Enhancements
- **Real-time dashboard**: Show live staff performance metrics
- **Gamification**: Display leaderboard on staff tablets
- **Automated bonuses**: Calculate and pay commissions automatically
- **Target tracking**: Set monthly goals per staff member
- **Alerts**: Notify managers of exceptional performance
